# Sales Doctor 2.0 — прототип

Кликабельный MVP-прототип CRM для полевых продаж: клиенты, заказы, дебиторка, маршрут агента, KPI и склад.

## Как открыть
Откройте `index.html` в браузере. Установка не требуется.

## Что внутри
- Дашборд руководителя: продажи, план/факт, дебиторка, просрочки.
- Клиенты: поиск, долги, статусы, создание клиента.
- Заказы: создание, статусы, CSV-экспорт.
- Дебиторка: текущий долг и просрочка.
- KPI: план/факт, визиты, конверсия, рейтинг агентов.
- Маршрут агента: визиты и быстрое создание заказа.
- Склад: товары, цены и остатки.
- Роли: руководитель, супервайзер, агент, финансист.

## Деплой
Можно опубликовать через GitHub Pages, Vercel или Netlify. Для GitHub Pages выберите branch `main`, папку `/root`.
